# Fábrica MINDTUBE · By Thalia Ruiz

Fábrica de vídeos animados 2D con Claude, para la comunidad.

- Página de descarga: https://thaliaruizmc.github.io/fabrica-mindtube/
- Instalación: `instalar-en-linea/MENSAJE PARA ALUMNAS.md`
- El paquete (`FabricaMINDTUBE.zip`) está en [Releases](../../releases/latest). La Fábrica se actualiza sola desde ahí.

El uso de la Fábrica requiere entrar con Google con la cuenta de la comunidad.
